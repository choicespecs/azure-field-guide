Docs & links

Primary sources first. Azure renames and retires things often, so trust current Microsoft docs over blog posts more than a year old.

Official docs & guidance

  • Azure documentationService docs, quickstarts and API references
  • Azure Architecture CenterReference architectures, design patterns, technology choice guides
  • Well-Architected FrameworkPillars, service guides, assessments
  • Cloud Adoption FrameworkLanding zones, governance, naming and tagging
  • Bicep documentationLanguage reference and resource type schemas
  • Azure UpdatesPreviews, GA announcements and retirements
  • Pricing calculatorEstimate before you build
